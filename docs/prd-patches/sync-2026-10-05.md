## New findings

**A parse-time crash in `dump` and `export`** (fixed in `643d6b8`). The global
`--output` and the two subcommand `--output` flags collided on clap's arg id,
panicking before any work. This broke the primary documented invocation of two
of five subcommands, including the README quickstart. Introduced in `eed0d09`;
survived because the only CLI test exercised `import`, which has no `--output`.

This is a **seventh instance** of the defect shape the August audit named — a
capability built and never exercised — and the most severe, because it was a
crash rather than a silent gap. It is worth recording as a pattern in its own
right: *a flag declared `global = true` silently collides with any subcommand
flag of the same name, and the failure is a runtime panic rather than a build
error, so only actually running each documented invocation finds it.*

Detection method that would have caught it: run every invocation in the README
and the CLI reference once, in CI. None of the 275 tests did.
